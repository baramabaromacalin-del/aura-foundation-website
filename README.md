# AURA Foundation Website

> Eliminating Female Genital Mutilation: One Purposeful Step at a Time.

Official modern, responsive web application for the **AURA Foundation**, dedicated to raising awareness, advocating for female bodily autonomy, protecting children's rights, and empowering communities.

## 🚀 Pages Included
- **Home:** Hero section, core mission pillars, global impact statistics, and survivor stories.
- **About Us:** Our story, values (Dignity, Safety, Empowerment), and leadership vision.
- **Female Rights:** Advocacy, education, and community dialogues to dismantle harmful practices.
- **Children's Rights:** Youth protection programs, safe havens, and education access.
- **Contact Us:** Interactive contact portal and headquarters information.
- **Donation Portal:** Multi-tier donation component ready for payment integration.

## 🛠 Tech Stack
- **Framework:** React 19 + Vite
- **Routing:** React Router (HashRouter for zero-config GitHub Pages compatibility)
- **Icons:** Lucide React
- **Styling:** Modern responsive CSS with custom design tokens

## 📦 Local Development
```bash
npm install
npm run dev
```

## 🌐 Production Build
```bash
npm run build
```
